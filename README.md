# Year 10 Revision Hub

A static AQA GCSE revision website designed for UK Year 10 students.

## Included
- AQA subject hub for Maths, English Language, English Literature, Combined Science, Geography, Computer Science and French
- Topic checklists with progress saved in the browser
- Search and subject filtering
- Weekly revision planner
- Retrieval-practice quiz
- Dark mode
- Official AQA resource links
- GitHub Pages deployment workflow

## Deploy
1. Create a GitHub repository and upload these files.
2. Push to the `main` branch.
3. In **Settings → Pages**, select **GitHub Actions** as the source.
4. The workflow deploys the site automatically after pushes to `main`.

GitHub Pages supports static files and GitHub Actions deployment. See:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
